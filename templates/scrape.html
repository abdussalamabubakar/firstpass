What happens: the agent fetches the homepage plus a bounded set of research pages (about, pricing, services, contact, careers, blog — max 6 pages), compiles the published facts into a scraped data section saved as CSV and JSON with the run, then feeds the compiled data to the AI (via OpenRouter when LLM_API_KEY is set; transparent deterministic engine otherwise) for the intelligence briefing and a verdict — and the final say stays with you.

Safety rules (enforced, tested):
  • Polite by design: descriptive User-Agent, 1s delay between requests, retries with backoff
  • robots.txt honored · single domain · max 6 pages · 1 MB per page · 10s timeout
  • Executable/installer URLs (the fixture's .exe trap) are never fetched
  • Internal/private network addresses are refused (SSRF guard)
  • Scraped text is untrusted data — planted instructions cannot steer the agent
